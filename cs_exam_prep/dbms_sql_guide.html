2026 MCQ 1 Mark Keys
Q12. A table has two candidate keys, one of which is chosen as the primary key. How many alternate keys does this table have?
(A) 0
(B) 1
(C) 2
(D) 3
✅ Official CBSE Marking Scheme Answer:

(B) 1

Marking Scheme Rubric: (1 Mark for writing the correct option)

Rule: Alternate Keys = Total Candidate Keys - 1 (chosen as Primary Key). Here, $2 - 1 = 1$.

2026 MCQ 1 Mark DDL Commands
Q13. Which of the following SQL command can change the degree of the existing relation?
(A) DROP TABLE
(B) ALTER TABLE
(C) UPDATE...SET
(D) DELETE
✅ Official CBSE Marking Scheme Answer:

(B) ALTER TABLE

Marking Scheme Rubric: (1 Mark for writing the correct option)

Concept Note: Degree is the number of attributes/columns in a relation. `ALTER TABLE table_name ADD column` increases the degree, while `ALTER TABLE table_name DROP COLUMN column` decreases the degree.

2026 MCQ 1 Mark Degree & Cardinality
Q15. A relation in MySQL database consists of 2 tuples and 3 attributes. If 2 attributes are deleted and 4 tuples are added, what will be the cardinality of the relation?
(A) 4
(B) 5
(C) 6
(D) 7
✅ Official CBSE Marking Scheme Answer:

(C) 6

Marking Scheme Rubric: (1 Mark for writing the correct option)

Calculation: Cardinality is the total number of rows (tuples). Initial tuples = 2. Added tuples = 4. New Cardinality = $2 + 4 = 6$. (Note: Deleting attributes changes the degree, from 3 to 1, but has no effect on cardinality!).

2026 Assertion & Reason 1 Mark Primary Key Constraint
Q21. Assertion (A): The PRIMARY KEY constraint in SQL ensures that each value in the column(s) is unique and cannot be NULL.
Reason (R): Candidate keys are not eligible to become a primary key.
(A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation for Assertion (A).
(B) Both Assertion (A) and Reason (R) are true and Reason (R) is not the correct explanation for Assertion (A).
(C) Assertion (A) is true, but Reason (R) is false.
(D) Assertion (A) is false, but Reason (R) is true.
✅ Official CBSE Marking Scheme Answer:

(C) Assertion (A) is true, but Reason (R) is false.

Marking Scheme Rubric: (1 Mark for writing the correct option)

Reasoning: Primary Key columns are strictly UNIQUE and NOT NULL. Reason (R) is completely false because candidate keys ARE the eligible candidates from which the primary key is selected.

2025 MCQ 1 Mark DDL vs DML
Q13. Which of the following is a DML command in SQL?
(A) UPDATE
(B) CREATE
(C) ALTER
(D) DROP
✅ Official CBSE Marking Scheme Answer:

(A) UPDATE

Marking Scheme Rubric: (1 Mark for writing the correct option)

Classification: DDL (Data Definition Language) defines table schema: CREATE, ALTER, DROP. DML (Data Manipulation Language) manipulates row data: INSERT, UPDATE, DELETE.

Q14. Which aggregate function in SQL displays the number of values in the specified column ignoring the NULL values?

Important Distinction: COUNT(column_name) counts non-NULL values only. COUNT(*) counts all rows in the table including rows containing NULLs.

2025 MCQ 1 Mark Data Types
Q15. In MYSQL, which type of value should not be enclosed within quotation marks?
(A) DATE
(B) VARCHAR
(C) FLOAT
(D) CHAR
✅ Official CBSE Marking Scheme Answer:

(C) FLOAT

Marking Scheme Rubric: (1 Mark for writing the correct option)

Rule: Numeric data types (INT, FLOAT, DECIMAL) are written bare without quotes. String types (CHAR, VARCHAR) and Date/Time types (DATE e.g. '2026-03-25') must always be enclosed in single or double quotes.

2025 True or False 1 Mark Cartesian Product
Q16. State True or False:
If table A has 6 rows and 3 columns, and table B has 5 rows and 2 columns, the Cartesian product of A and B will have 30 rows and 5 columns.
✅ Official CBSE Marking Scheme Answer:

True

Marking Scheme Rubric: (1 Mark for writing the correct answer)

Formulas for Cartesian Product ($A imes B$):
• Cardinality (Rows) = $ ext{Rows}(A) imes ext{Rows}(B) = 6 imes 5 = 30$
• Degree (Columns) = $ ext{Cols}(A) + ext{Cols}(B) = 3 + 2 = 5$

2023 Concept & Example 2 Marks Alternate Key
Q22. Explain the concept of ‘‘Alternate Key’’ in a Relational Database Management System with an appropriate example.
✅ Official CBSE Marking Scheme Answer:

Definition: Alternate Keys are all the Candidate Keys of a table in RDBMS which have NOT been chosen as the Primary Key.

Example:
RegNoAadhaarNoName
123456123456789012Abraham Sen
123458123456789123Umeed Singh

In this example, both RegNo and AadhaarNo are Candidate Keys. If RegNo is chosen as the Primary Key, then AadhaarNo becomes the Alternate Key.

Marking Scheme Rubric: (2 marks for explaining Alternate Keys with example) OR (1 mark for writing example without explanation) OR (1 mark only for definition)
2023 Distinction 2 Marks CHAR vs VARCHAR
Q25. Differentiate between CHAR and VARCHAR data types in SQL with appropriate example.
✅ Official CBSE Marking Scheme Answer:
CHAR(n)VARCHAR(n)
Fixed-length character data type. Always allocates exactly $n$ bytes of storage regardless of actual string length. Variable-length character data type. Allocates only as much storage as the actual length of characters plus 1-2 bytes of length prefix.
If a string with length less than $n$ is stored, spaces are right-padded to complete $n$ characters (wastes memory). No trailing space padding is added; saves memory space.
Example: Gender CHAR(1), Grade CHAR(2). Storing 'A' in CHAR(10) occupies all 10 bytes. Example: Address VARCHAR(50). Storing 'A' in VARCHAR(10) occupies only 1 byte (+1 length byte).
Marking Scheme Rubric: (1 mark each for correct difference of CHAR and VARCHAR with example)
2022 Distinction 2 Marks Attribute vs Domain
Q3. Differentiate between the terms Attribute and Domain in the context of Relational Data Model.
✅ Official CBSE Marking Scheme Answer:
AttributeDomain
A column or named field of a table/relation is known as an attribute. It is a pool / set of permissible and legal values from which an attribute can take its value.
Example: In table Student(Name, Class, Marks), Name, Class, and Marks are attributes. Example: The attribute Class has a domain of permissible values like { 'XI', 'XII' }; Marks has domain of real numbers between 0 and 100.
Marking Scheme Rubric: (1 mark each for writing any correct explanation of Attribute and Domain with example)
2022 Distinction 2 Marks Candidate Key vs Primary Key
Q7. Differentiate between Candidate Key and Primary Key in the context of Relational Database Model.
✅ Official CBSE Marking Scheme Answer:
Candidate KeyPrimary Key
All attributes or sets of attributes in a relation that are uniquely capable of identifying each record/tuple are Candidate Keys. The particular candidate key selected by the database administrator/designer to uniquely identify each row in the table is the Primary Key.
A table can have multiple candidate keys. A table can have only one primary key.
Marking Scheme Rubric: (1 mark each for correct difference between Candidate Key and Primary Key)
2026 DDL Table Design 2 Marks CREATE TABLE & ALTER TABLE
Q27. Ms. Zoya is a Production Manager in a factory which packages mineral water. She decides to create a table in a database to keep track of the stock present in the factory. Each record of the table will have the following fields:
• W_Code – Code of the item (type – CHAR(5))
• W_Description – Description of the item (type – VARCHAR(20))
• B_Qty – Balance quantity of the item (type – INTEGER)
• U_Price – Unit Price of the item (type – FLOAT)
The name of the table is W_STOCK.

(i) (a) Write an SQL command to create the above table (W_Code should be the primary key). [1M]
OR (b) Can U_Price be the primary key of the above table? Justify your answer. [1M]

(ii) (a) Assuming that the table W_STOCK is already created, write an SQL command to add an attribute E_Date (of DATE type) to the table. [1M]
OR (b) Assuming that the table W_STOCK is already created, write an SQL command to remove the column B_Qty from the table. [1M]
✅ Official CBSE Marking Scheme Answer:

(i) (a) CREATE TABLE:

CREATE TABLE W_STOCK (
    W_Code CHAR(5) PRIMARY KEY,
    W_Description VARCHAR(20),
    B_Qty INTEGER,
    U_Price FLOAT
);

(½ mark for CREATE TABLE, ½ mark for correct column names and data types)

OR (b) No, U_Price cannot be the primary key because multiple items can have the same price (duplicate values) or price could be NULL.

(½ mark for 'No', ½ mark for justification)

(ii) (a) Add Column:

ALTER TABLE W_STOCK ADD E_Date DATE;
-- OR: ALTER TABLE W_STOCK ADD COLUMN E_Date DATE;

(½ mark for ALTER TABLE, ½ mark for ADD COLUMN E_Date DATE)

OR (b) Drop Column:

ALTER TABLE W_STOCK DROP B_Qty;
-- OR: ALTER TABLE W_STOCK DROP COLUMN B_Qty;

(½ mark for ALTER TABLE, ½ mark for DROP COLUMN B_Qty)

Q34. Assume that you are the Manager of the Loans department of a Finance House. To keep track of the loans you have created two tables : CUSTOMERS and LOANS. The sample data in these tables is given below:
Table: CUSTOMERS
C_IDC_NamePhone
00001Raj Malhotra1234567890
00003David Xavier3456789012
00004Damini Iyer3156789012
00008Abdul2345678901
Table: LOANS
SNoC_IDL_AmtL_Date
1000011000002020-05-15
200003500002021-08-20
3000012000002022-01-10
4000041500002023-11-05
Write SQL queries for (i) to (iv):
(i) Display the customer name and total loan amount taken by each customer. [1M]
(ii) Display customer ID, customer name, loan amount, and loan date for all loans taken after '2021-01-01'. [1M]
(iii) Display details of all customers whose name ends with the letter 'r'. [1M]
(iv) Increase the loan amount by 10% for the customer whose C_ID is '00003'. [1M]
✅ Official CBSE Marking Scheme Queries:

(i) Group By Join query:

SELECT C_Name, SUM(L_Amt) 
FROM CUSTOMERS C, LOANS L 
WHERE C.C_ID = L.C_ID 
GROUP BY C.C_ID, C_Name;

(½ mark for SELECT and WHERE join, ½ mark for GROUP BY C_Name)

(ii) Equi-Join with Date Filter:

SELECT C.C_ID, C_Name, L_Amt, L_Date 
FROM CUSTOMERS C, LOANS L 
WHERE C.C_ID = L.C_ID AND L_Date > '2021-01-01';

(½ mark for SELECT and FROM, ½ mark for correct WHERE join and date condition)

(iii) Pattern Matching (LIKE):

SELECT * FROM CUSTOMERS 
WHERE C_Name LIKE '%r';

(½ mark for SELECT, ½ mark for WHERE C_Name LIKE '%r')

(iv) Update Statement:

UPDATE LOANS 
SET L_Amt = L_Amt * 1.10 
WHERE C_ID = '00003';

(½ mark for UPDATE LOANS SET L_Amt = L_Amt * 1.10, ½ mark for WHERE C_ID = '00003')

2022 Query Writing 4 Marks (4 x 1) Multi-Table Queries
Q11. Write SQL queries for (a) to (d) based on the tables PASSENGER and FLIGHT given below:

Table: FLIGHT (FNO, START, END, FARE)

Table: PASSENGER (PNO, NAME, GENDER, FNO, F_DATE)

(a) Write a query to change the fare to 6000 of the flight whose FNO is 'F104'. [1M]
(b) Write a query to display the total number of MALE and FEMALE PASSENGERS. [1M]
(c) Write a query to display the NAME, corresponding FARE and F_DATE of all PASSENGERS who have a flight to START from 'DELHI'. [1M]
(d) Write a query to delete the records of flights which end at 'MUMBAI'. [1M]
✅ Official CBSE Marking Scheme Queries:

UPDATE FLIGHT 
SET FARE = 6000 
WHERE FNO = 'F104';

(½ Mark for UPDATE FLIGHT, ½ Mark for SET FARE=6000 WHERE FNO="F104")

SELECT GENDER, COUNT(*)

2026 Python-MySQL Script 4 Marks mysql.connector / pymysql
Q35. Peter has created a table named Account in MySQL database, SCHOOL, having following structure:
• Stud_id – integer
• Sname – string
• Class – string
• Fees – float

Help him in writing a Python program to display records of those students whose fees is less than 5000.
Note the following to establish connectivity between Python and MySQL:
• Username – admin
• Password – root
• Host - localhost
✅ Official CBSE Marking Scheme Code:
import mysql.connector as pm   # OR import pymysql as pm

# 1. Establish connection
DB = pm.connect(
    host='localhost',
    user='admin',
    password='root',
    database='SCHOOL'
)

# 2. Create cursor object
CUR = DB.cursor()

# 3. Formulate and execute SQL query
SQL = "SELECT * FROM Account WHERE Fees < 5000"
CUR.execute(SQL)

# 4. Fetch and display all matching records
Data = CUR.fetchall()
for D in Data:
    print(D)

# 5. Clean up connection
DB.close()
Marking Scheme Rubric: (1 Mark for importing library & establishing connection) + (1 Mark for creating cursor & executing query) + (1 Mark for fetchall()) + (1 Mark for loop & printing records)
