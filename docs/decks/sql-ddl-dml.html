What is SQL?

SQL

●SQL = Structured Query Language, pronounced “ess-cue-ell” or “sequel”

●The standard language for creating, changing and querying relational databases

●Used by MySQL, Oracle, PostgreSQL, SQL Server and many others

●It is declarative: you say WHAT you want, not HOW to get it

WHAT SQL LETS YOU DO

Create databases and tables

Store, change and delete data

Ask questions (queries) about the data

Control constraints such as keys

We use MySQL syntax in this deck.

SQL Syntax Rules

SYNTAX RULES

●Keywords are not case-sensitive: select = SELECT

●Every statement ends with a semicolon ;

●Text and dates go inside single quotes: 'Delhi', '2008-05-17'

●Numbers are written without quotes: 12, 85.5

●Table and column names are best kept in one consistent style

A WELL-FORMED STATEMENT

SELECT Name, Marks

FROM STUDENT

WHERE City = 'Delhi';

Line breaks are optional; the semicolon ends the statement.

-- anything after two dashes is a comment

DDL vs DML: A Simple Picture

DDL vs DML

Think of a table as a cupboard.

DDL = BUILD THE CUPBOARD

CREATE: build a new cupboard (table)

ALTER: add or remove a shelf (column)

DROP: throw the whole cupboard away

Changes the structure

DML = USE THE CUPBOARD

INSERT: put new items in

SELECT: look at the items

DELETE: take items out

Changes or reads the contents

CHAR(n) vs VARCHAR(n)

CHAR vs VARCHAR

Both store text. The difference is how much space they use.

CHAR(n): FIXED LENGTH

Always uses exactly n characters

Shorter values are padded with spaces

Best for values of the same size: Gender, PIN code

CHAR(6) holding 'Hi' → 'Hi    '

VARCHAR(n): VARIABLE LENGTH

Uses only the space the value needs, up to n

No padding

Best for values of different size: Name, City, Address

VARCHAR(6) holding 'Hi' → 'Hi'

INT, FLOAT and DATE

INT FLOAT DATE

●INT stores whole numbers, with no decimal point

●FLOAT stores numbers with decimals, e.g. marks like 85.5

●DATE stores a calendar date in the format YYYY-MM-DD (year-month-day)

●Write a DATE inside quotes, like text: '2008-05-17'

●Numbers (INT, FLOAT) are never quoted

VALID VALUES

Class INT  →  12

Marks FLOAT  →  85.5

DOB DATE  →  '2008-05-17'

DATE is year first: 2008-05-17 is 17 May 2008.

NOT NULL Constraint

NOT NULL

●NOT NULL means the column can never be left empty

●NULL means “no value”, not zero and not a blank space

●Use it for essential data such as a student's name

●Adding a row without that value gives an error

SQL

CREATE TABLE STUDENT (

  RollNo INT,

  Name VARCHAR(30) NOT NULL

);

INSERT INTO STUDENT (RollNo, Name)

VALUES (7, NULL);

OUTPUT (error)

ERROR 1048 (23000):

Column 'Name' cannot be null

UNIQUE Constraint

UNIQUE

●UNIQUE means no two rows may share the same value in that column

●A table can have several UNIQUE columns

●A UNIQUE column may hold NULL (NULL is not a value)

●Typical use: email address, Aadhaar number

SQL

CREATE TABLE CUSTOMER (

  CustID INT PRIMARY KEY,

  Email VARCHAR(40) UNIQUE

);

INSERT INTO CUSTOMER VALUES (1, 'a@x.com');

INSERT INTO CUSTOMER VALUES (2, 'a@x.com');

OUTPUT (second INSERT)

ERROR 1062 (23000): Duplicate entry

'a@x.com' for key 'customer.Email'

PRIMARY KEY Constraint

PRIMARY KEY

●Uniquely identifies every row of the table

●Value must be unique AND not NULL

●Only one primary key per table

●Choose a short column that never changes, like RollNo

SQL

CREATE TABLE STUDENT (

  RollNo INT PRIMARY KEY,

  Name VARCHAR(30)

);

INSERT INTO STUDENT VALUES (1, 'Riya');

INSERT INTO STUDENT VALUES (1, 'Amit');

OUTPUT (second INSERT)

ERROR 1062 (23000): Duplicate entry

'1' for key 'student.PRIMARY'

DROP DATABASE

DROP DATABASE

●Permanently deletes a database and ALL its tables and data

●Syntax: DROP DATABASE database_name;

●It cannot be undone, so be very careful

WARNING

There is no recycle bin. Dropping a database erases its tables and every row inside them.

SQL

DROP DATABASE school;

OUTPUT

Query OK, 1 row affected (0.02 sec)

The count is the number of tables removed (here, 1). Afterwards SHOW DATABASES no longer lists school.

DISTINCT: Remove Duplicates

DISTINCT

●DISTINCT shows each different value only once

●Syntax: SELECT DISTINCT column FROM table;

Order of Operators: Use Brackets

PRECEDENCE

●NOT is evaluated first, then AND, then OR

●So A OR B AND C means A OR (B AND C)

●Use brackets ( ) to force the order you intend

●Different brackets can give different rows

SQL

SELECT Name FROM STUDENT

WHERE City='Pune' OR City='Delhi' AND Class=11;

SELECT Name FROM STUDENT

WHERE (City='Pune' OR City='Delhi') AND Class=11;

OUTPUT

No brackets:  Amit, Sana, Neha, Arjun

With brackets: Sana, Arjun

Without brackets, AND ran first: Delhi AND Class 11 (Sana, Arjun), OR Pune (Amit, Neha).

Tricky: WHERE Traps

GOTCHA

Four mistakes students make again and again:

WHERE Marks > 80 AND < 90

✗  Error

Repeat the column: Marks > 80 AND Marks < 90.

WHERE City = Delhi

(no quotes)

✗  Unknown column 'Delhi'

Text values need single quotes: City = 'Delhi'.

WHERE Marks = NULL

✗  Returns no rows

NULL is not a value. Use IS NULL, not = NULL.

SELECT Marks+5 AS Bonus

FROM STUDENT WHERE Bonus > 90

✗  Unknown column 'Bonus'

WHERE cannot use an alias. Write Marks + 5 > 90.

SQL is the standard language for relational databases. DDL defines structure (CREATE, ALTER, DROP); DML works with data (INSERT, DELETE, SELECT)

Data types: CHAR(n) fixed, VARCHAR(n) variable, INT, FLOAT, DATE. Constraints: NOT NULL, UNIQUE, PRIMARY KEY

5

WHERE filters rows with relational (= <> < > <= >=) and logical (AND, OR, NOT) operators; text and dates go in quotes
