What are Network Devices?

OVERVIEW

●Hardware that connects computers and other devices so they can send and receive data

●Each device has its own job in the network

●Some connect one device, some connect many devices, some connect whole networks

●Using the wrong device gives a slow or broken network

FIVE JOBS

Connect a device:  NIC, Wi-Fi card, RJ45

Convert signals:  Modem

Boost signals:  Repeater

Link devices in a LAN:  Hub, Switch

Link networks:  Router, Gateway

ETHERNET CARD

MAC Address

MAC ADDRESS

●MAC = Media Access Control address

●A physical address fixed into the NIC by the manufacturer

●48 bits = 6 bytes, written as 12 hexadecimal digits

●Meant to be unique for every network card in the world

●Switches use MAC addresses to deliver data inside a LAN

EXAMPLE

00:1A:2B:3C:4D:5E

00:1A:2B

= manufacturer part (first 3 bytes)

3C:4D:5E

= serial number of this card (last 3 bytes)

Repeater

REPEATER

●Signals weaken (attenuate) as they travel along a cable

●A repeater receives the weak signal, regenerates it and sends it on

●Extends the distance a network segment can cover

●Works on signals: does not read or filter the data

●Used on long cable runs, optical links and as Wi-Fi range extenders

REMEMBER

A repeater is a signal booster. Same data, stronger signal.

Repeater

19 / 62

Attenuation and Regeneration

ATTENUATION

●Attenuation = loss of signal strength with distance

●Noise from the surroundings also distorts the signal

●The repeater sits on the cable before the signal is lost

●It creates a fresh, full-strength copy of the signal

●More repeaters allow longer networks, up to the network's limits

Twisted-pair Ethernet works up to about 100 m. A repeater lets the signal go further.

Repeater

20 / 62

Repeater vs Amplifier

TRICKY

Both make a signal stronger, but they treat noise differently:

REMEMBER

Repeater: regenerates digital signals

Amplifier: boosts analog signals and noise together

Neither one filters data or makes it faster

Exam point: a repeater extends distance, not speed. It repeats everything it receives, including unwanted traffic.

HUB

●Connects several computers in a LAN (star topology)

●Each computer is joined to a port by an RJ45 cable

●Data received on one port is sent out on ALL other ports

How a Hub Sends Data

BROADCAST

●PC A sends data meant for PC D

●The hub copies the data to every other port

●PC B and PC C receive it and discard it

●Only PC D accepts it, because it carries D's address

●Only one device can send at a time, or collisions occur

accepts the data

All ports share the bandwidth. More PCs means more waiting.

Hub

What is it?

A multi-port device that connects the computers of a LAN in a star topology.

How it works

Copies the data from one port to all other ports (broadcast).

Intelligence

None. It works on signals and does not read addresses.

Weakness

Shared bandwidth, collisions, and anyone can capture the data.

Duplex

Half-duplex: it can send or receive, not both at once.

Remember

One speaks, everyone hears. Switches replaced hubs.

Switch

SWITCH

●Connects several computers in a LAN, like a hub, but is intelligent

●Reads the destination MAC address of every frame

●Sends the data only to the port of the intended receiver

●Learns addresses and keeps a MAC address table

●Each port has its own bandwidth and works full-duplex

REMEMBER

A switch is a smart hub: private delivery inside one LAN.

●1  A frame arrives: the switch notes the sender's MAC address and the port it came from

How a Gateway Translates

TRANSLATION

Like an interpreter between two people who speak different languages:

1

Receive

Data arrives from Network A in Protocol X.

2

Translate

The gateway converts it to the rules of Protocol Y.

3

Repackage

It adds the headers and format Network B expects.

4

Forward

The data is sent into Network B and understood there.

Routers pass packets between networks of the same kind. Gateways also change the protocol.

Myth vs Fact

MYTH vs FACT

Common mistakes in exams and in real life:

Myth: Modem = router

Fact: the modem connects to the ISP. The router shares the connection and directs traffic.

Often in one box, but two jobs

Myth: Switch joins networks

Fact: a switch connects devices inside one LAN. A router connects networks.

Switch = devices, router = networks

Myth: Hub sends to one PC

Fact: a hub broadcasts to all ports. Only a switch sends to one port.

One speaks, everyone hears

Myth: Repeater adds speed

Fact: it extends distance by regenerating the signal. Speed is unchanged.

Distance, not speed

Myth: Wi-Fi card has no MAC

Fact: every network card, wired or wireless, has its own MAC address.

NIC = Ethernet or Wi-Fi

Myth: RJ45 is a device

Fact: it is only a connector (plug) at the end of a cable.

No processing of data
