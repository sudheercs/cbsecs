Introduction to Lists

type: list

●A list is an ordered, mutable collection of items enclosed in square brackets [ ]

●Items can be of any type — a single list can even mix types

●Lists belong to the built-in list class

●Elements are indexed starting at 0, just like strings

lst = [10, "Python", 3.14, True]

print(lst)

print(type(lst))

Output

[10, 'Python', 3.14, True]

<class 'list'>

Creating Lists

list()

●Square brackets [1, 2, 3] create a list directly

●list() converts another iterable — a string, tuple or range — into a list

Lists Are Mutable

MUTABLE

●Unlike strings, list elements CAN be changed after creation

●Assigning to lst[i] updates that element in place

●The list's identity, id(), stays the same after the change

●This is the single biggest difference between lists and strings

lst = [1, 2, 3]

print(id(lst))

lst[0] = 100

print(lst, id(lst))

Output (illustrative)

140723456789104

[100, 2, 3] 140723456789104  # same!

5 / 31

Tricky: Mutability & Aliasing Traps

GOTCHA

The mutability that makes lists powerful also makes them tricky:

a = [1, 2, 3]

b = a

b.append(4)

print(a)

→  [1, 2, 3, 4]

b = a does NOT copy the list — both names point to the exact same object.

a = [1, 2, 3]

b = a.copy()

b.append(4)

print(a)

→  [1, 2, 3]

.copy() (or a[:]) makes an independent copy — a is left untouched.

def add_item(lst):

    lst.append(99)

nums = [1, 2]

add_item(nums)

print(nums)

→  [1, 2, 99]

Lists passed into a function are shared — the function can modify the caller's list.

Indexing (Positive)

lst[i]

●Every element has a position starting at index 0

●lst[0] is the first element

●lst[len(lst)-1] is always the last element

●10(0)  20(1)  30(2)  40(3)  → indices for [10, 20, 30, 40]

print(lst[0], lst[2])

Negative Indexing

lst[-i]

●Negative indices count backward from the end

●lst[-1] is always the last element

●lst[-len(lst)] is the same as lst[0]

●Handy for reaching the end without knowing the list's length

Tricky: IndexError Examples

GOTCHA

Indexing is strict about bounds — slicing (next) is not:

lst = [1, 2, 3]

print(lst[5])

✗  IndexError

Valid index range is ‑len(lst) to len(lst)−1. Index 5 is out of range.

lst = []

print(lst[0])

✗  IndexError

An empty list has no valid index at all, positive or negative.

lst = [1, 2, 3]

lst[5] = 100

✗  IndexError

Assignment also needs an EXISTING index — it can't grow the list this way.

11 / 31

Tricky: Repetition Aliasing Trap

GOTCHA

The most infamous list bug on any exam paper:

rows = [[0, 0]] * 3

rows[0][0] = 9

print(rows)

→  [[9,0], [9,0], [9,0]]

* copies REFERENCES, not the inner lists — all three rows are the same object!

rows = [[0, 0] for _ in range(3)]

rows[0][0] = 9

print(rows)

→  [[9,0], [0,0], [0,0]]

A list comprehension builds a genuinely new inner list on every pass.

a = [1, 2] * 0

print(a)

→  []

Repeating by 0 (or a negative number) gives an empty list, just like strings.

Tricky: Slicing Gotchas

GOTCHA

Slicing can do far more than just “read” a list:

lst = [1, 2, 3, 4, 5]

lst[1:3] = [20, 30, 40]

print(lst)

→  [1,20,30,40,4,5]

Slice assignment can change the list's LENGTH — 2 items replaced by 3.

lst = [1, 2, 3, 4, 5]

del lst[1:3]

print(lst)

→  [1, 4, 5]

del with a slice removes a whole range of elements in one go.

lst = [1, 2, 3]

print(lst[10:20])

→  []

Out-of-range slice bounds return an empty list, never an error.

append() vs extend()

append/extend

Both add data to a list — but never confuse the two:

append()

lst = [1, 2]

lst.append([3, 4])

print(lst)

→  [1, 2, [3, 4]]

append() always adds its argument as ONE single element — even a whole list.

extend()

lst = [1, 2]

lst.extend([3, 4])

print(lst)

→  [1, 2, 3, 4]

extend() unpacks the argument and adds each of its elements individually.

remove() vs pop() vs del

remove/pop/del

Three ways to delete — each behaves differently:

remove()

lst = [10, 20, 30]

lst.remove(20)

print(lst)

→  [10, 30]

Removes by VALUE — the first matching element found.

pop()

lst = [10, 20, 30]

x = lst.pop(1)

print(lst, x)

→  [10, 30] 20

Removes by INDEX and also returns the removed value.

del

lst = [10, 20, 30]

del lst[1]

print(lst)

→  [10, 30]

A statement, not a method — removes by index but returns nothing.

sort() vs sorted()

sort/sorted

One of the most common exam traps in the whole chapter:

sort()

lst = [3, 1, 2]

result = lst.sort()

print(lst, result)

→  [1, 2, 3] None

Modifies the list in place and always returns None — never write lst = lst.sort().

sorted()

lst = [3, 1, 2]

new = sorted(lst)

print(lst, new)

→  [3,1,2] [1,2,3]

Leaves the original list untouched and returns a brand-new sorted list.

Tricky: Nested List Traps

GOTCHA

Nested lists combine EVERY trap seen so far — read carefully:

grid = [[0]*3] * 3

grid[0][0] = 9

print(grid)

→  [[9,0,0],[9,0,0],[9,0,0]]

The same aliasing trap, now with rows — every row is the SAME inner list.

matrix = [[1,2], [3,4]]

for row in matrix:

    print(sum(row))

→  3

7

Looping over a nested list gives you each inner list, one at a time.

matrix = [[1,2], [3,4]]

print(matrix[2][0])

✗  IndexError

The outer index (2) must be valid too — there are only 2 rows (index 0‑1).

Program: Maximum, Minimum & Mean

PROGRAM

Find the largest, smallest and average of numbers stored in a list:

numbers = [23, 45, 12, 67, 34, 89, 10]

maximum = minimum = numbers[0]

total = 0

for num in numbers:

    if num > maximum:

        maximum = num

    if num < minimum:

        minimum = num

    total = total + num

mean = total / len(numbers)

print("Maximum =", maximum)

print("Minimum =", minimum)

print("Mean =", round(mean, 2))

Sample Output

Maximum = 89

Minimum = 10

Mean = 40.0

Program: Linear Search

PROGRAM

Search a list of numbers one element at a time until a match is found:

def linear_search(lst, target):

    for i in range(len(lst)):

        if lst[i] == target:

            return i

    return -1

marks = [56, 78, 90, 45, 67]

pos = linear_search(marks, 90)

if pos != -1:

    print("Found at index", pos)

else:

    print("Not found")

Sample Output

Found at index 2

Program: Counting Frequency of Elements

PROGRAM

Count how many times each value occurs in a list, using a dictionary:

data = [3, 5, 3, 2, 5, 5, 8, 2]

freq = {}


for item in data:

    if item in freq:

        freq[item] = freq[item] + 1

    else:

        freq[item] = 1


for key, value in freq.items():

    print(key, ":", value)

Sample Output

3 : 2

5 : 3

2 : 2

8 : 1

Rapid Fire: Common Exam Traps

TRAPS

Four one-liners that trip up almost every class — read carefully:

a = [1, 2, 3]

print(a * 2)

→  [1,2,3,1,2,3]

* repeats the WHOLE list — it does not multiply each element.

lst = [1, 2, 3]

print(lst.append(4))

→  None

append() modifies in place and returns None — printing it directly is a classic mistake.

print(len([[1,2],[3,4],[5]]))

→  3

len() on a nested list counts only the outer elements, whatever their own length.

a = [1, 2, 3]

b = [1, 2, 3]

print(a == b, a is b)

→  True False

== compares VALUES; is compares IDENTITY — equal lists can still be different objects.
