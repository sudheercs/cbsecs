Why Connect Python with MySQL?

WHY

●SQL is great at storing and searching data, but it cannot take input or make a menu

●Python can take input, apply logic, loops and display results

●Together they make real applications: school records, billing, ticket booking

●The bridge between them is a connector module

IN ONE LINE

Python = the program

MySQL = the data store

mysql.connector = the bridge that sends SQL queries and brings rows back

Why commit() is Needed

commit()

●INSERT, UPDATE and DELETE first change a temporary copy

●commit() saves the changes permanently

●If you close the connection without commit(), the changes are discarded

●SELECT and CREATE TABLE do not need commit()

Forgetting commit()

NO commit()

Facts about the %s Placeholder

%s

It is not the same as Python's % operator:

WHAT %s DOES

Use %s for every data type: int, float, text, date

The connector puts quotes around text for you

Number of %s must equal number of values

Values go in a tuple or list

WATCH OUT

A single value still needs a tuple: ("Delhi",)

Do not put quotes around %s in the query

Do not write %d or %f inside execute() queries

Pass the values as the second argument of execute()

INSERT using format()

format()

●{} marks the place where a value will go

●Text values need their own quotes: '{}'

●format() builds the final query string first

●Then execute(q) runs it

print(mycursor.rowcount, "record inserted")

% OPERATOR

●Python's % operator also builds the string first

print(mycursor.rowcount, "record inserted")

CHECKLIST

Before you run your program, check:

ALWAYS

import mysql.connector

connect() with correct host, user, passwd, database

mydb.cursor() to get a cursor

commit() after INSERT, UPDATE, DELETE

close() when finished

AVOID

Text values without quotes in format() queries

A single %s value without the comma: (value,)

UPDATE or DELETE without WHERE

format() with raw user input

A new query before reading the old result
