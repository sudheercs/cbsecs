What is a Computer Network?

NETWORK

●A computer network is a group of computers and other devices connected together so they can share data and resources

●Each connected device is called a node

●Nodes are linked by wired media (cables) or wireless media (radio waves)

●A network can be tiny (two phones) or huge (the whole Internet)

WHAT A NETWORK CONNECTS

Nodes:  PCs, laptops, phones, printers, servers

Links:  cables or wireless signals

Shares:  files, printers, software, Internet access

Examples: school computer lab, ATM network, the Internet

Why Do We Need Networks?

NEED

Six everyday benefits of connecting computers:

Resource Sharing

Many users share one printer, scanner or storage device instead of each owning one.

e.g. one printer for the whole lab

Communication

People exchange messages, files, voice and video quickly over long distances.

e.g. email, video calls

Saves Cost

Sharing hardware and software licences reduces what an organisation must buy.

e.g. one licence server for many PCs

Central Data

Data kept on a server stays up to date and is available to everyone who needs it.

e.g. school fee records

Reliability

If one machine fails, the data can still be reached from another one.

e.g. backup copies on other nodes

Easy to Grow

New computers can be added to a network without rebuilding it.

e.g. adding 10 PCs to a new lab

Before and After Networks

BEFORE / AFTER

Early computers worked alone; networking changed how they were used:

STAND-ALONE COMPUTERS

Each computer worked on its own

Data moved by carrying floppy disks or tapes between machines

Every computer needed its own printer and storage

Updating a file meant re-copying it to every machine

NETWORKED COMPUTERS

Computers exchange data instantly over links

Files and printers are shared across the network

One central copy of data can be updated once

Users anywhere can work together on the same data

Evolution of Networking: Timeline

TIMELINE

From four computers to billions of devices:

1969

ARPANET

First packet-switched network. Four US universities linked. Funded by ARPA of the US Department of Defense.

1983

TCP/IP adopted

ARPANET switches to TCP/IP, a common language that lets separate networks join together.

1985–86

NSFNET

High-speed backbone connecting universities and supercomputer centres across the USA.

1990s

The Internet

Commercial ISPs take over and the World Wide Web makes the Internet public and popular.

ARPANET (1969)

ARPANET

●ARPANET = Advanced Research Projects Agency Network

●Built with funding from ARPA, part of the US Department of Defense

●Goal: let researchers at different universities share computers and data

●It used packet switching, which was a new idea then

●1971: the first email program was written for it

KEY FACTS

29 Oct 1969: first message sent, from UCLA to Stanford Research Institute

The message was “LOGIN” — the system crashed after “LO”!

Four nodes by end of 1969

1983: adopted TCP/IP

Shut down in 1990

NSFNET (mid-1980s)

NSFNET

●NSFNET = National Science Foundation Network

●Created so that universities and supercomputer centres across the USA could share expensive resources

●It used TCP/IP and acted as a high-speed backbone linking regional networks

INTERNET

●The Internet is a worldwide network of networks, linking millions of smaller networks

●All of them follow one common set of rules: TCP/IP

●No single owner: ISPs, companies, universities and governments each run parts of it

●ARPANET and NSFNET grew into it; the 1990s brought commercial ISPs and the World Wide Web

NETWORK OF NETWORKS

Home Wi-Fi  +  School LAN

+  Company network  +  Mobile network

+  University network  +  ...

The Five Components

5 PARTS

What each component does:

1. Sender

The device that creates the message and sends it into the network.

e.g. your phone, a computer, a server

2. Receiver

The device that receives the message and presents it to the user.

e.g. a friend's phone, a printer

3. Message

The actual information being communicated, in the form of data.

e.g. text, picture, audio, video

4. Communication Medium

The physical path or channel that carries the signal from sender to receiver.

e.g. twisted pair, optical fibre, radio waves

5. Protocols

The agreed set of rules that governs how data is formatted, sent and received.

e.g. HTTP, FTP, SMTP, TCP/IP

Remember

Sender and receiver are devices, the message is data, the medium is the path, and protocols are rules.

Bandwidth

BANDWIDTH

●Bandwidth is the capacity of a communication medium to carry data

●Technically it is the difference between the highest and lowest frequencies a channel can carry, measured in Hertz (Hz)

●More bandwidth means more data can pass per second

●Analogy: the width of a pipe or the number of lanes on a road

FREQUENCY UNITS

1 KHz = 1000 Hz

1 MHz = 1000 KHz

1 GHz = 1000 MHz

Example: a voice channel carries 300 Hz to 3400 Hz, so bandwidth = 3400 − 300 = 3100 Hz

DATA RATE

●Data transfer rate is the number of bits transmitted per second between two devices

Transfer Time Calculations

CALCULATION

●Time (seconds) = File size in bits ÷ Data transfer rate in bps

●Convert bytes to bits first: 1 byte = 8 bits

●Make sure both use the same size of unit (K, M, G)

●Check your answer: faster rate, shorter time

WORKED EXAMPLES

Send 10 MB at 8 Mbps

10 MB = 80 Mb  →  80 ÷ 8 = 10 seconds

Send 1 MB at 512 Kbps

1 MB = 8192 Kb  →  8192 ÷ 512 = 16 seconds

IP Address

IP ADDRESS

●An IP (Internet Protocol) address is a unique numeric address given to every device on a network

●It works like a postal address: it tells the network where to deliver data

●IPv4: 32 bits, written as four decimal numbers separated by dots

●Each of the four numbers lies between 0 and 255

EXAMPLE ADDRESSES

8.8.8.8

Why Switching?

SWITCHING

●In a large network, not every pair of devices has a direct link

●Switching is the way data finds its path from sender to receiver through intermediate nodes

●It lets many devices share the same links instead of needing a cable for every pair

●Two main techniques: circuit switching and packet switching

THE PROBLEM WITH DIRECT LINKS

5 devices, all joined directly: 10 links

100 devices: 4950 links!

Links needed = n × (n − 1) ÷ 2

Switching shares a few links among many devices

Circuit Switching

CIRCUIT

●A dedicated path is set up between sender and receiver before any data is sent

●The path stays reserved for the whole communication, even during silence

●Used in the traditional telephone network

●Good: steady speed and data arrives in order

●Bad: setup delay, and wasted capacity when idle

THREE PHASES

1.  Connection setup — path is reserved

2.  Data transfer — whole message on the same path

3.  Disconnection — path is released

Packet Switching

PACKET

●The message is broken into small pieces called packets

●Each packet has a header with the source address, destination address and a sequence number

●Packets travel independently, maybe by different routes, and are put back in order at the destination

●No path is reserved, so many users share the links. The Internet works this way

ONE MESSAGE → FOUR PACKETS

Message:  HELLO WORLD!

Packet 1:  HEL

Packet 2:  LO_

Packet 3:  WOR

Packet 4:  LD!

(_ stands for the space)
