What is a Network Protocol?

PROTOCOL

●A protocol is a set of rules for how data is formatted, addressed, sent and received

●Both sides must follow the same protocol, like two people speaking the same language

●Different tasks use different protocols

●Protocols work together as a team, e.g. HTTP runs on top of TCP/IP

ONE TASK, ONE PROTOCOL

Browse a website  →  HTTP / HTTPS

Send an email  →  SMTP

Read an email  →  POP3

Transfer files  →  FTP

Log in remotely  →  Telnet

Make a voice call  →  VoIP

Deliver packets  →  TCP/IP

TCP/IP: The Foundation

TCP/IP

●TCP/IP is the suite of protocols that runs the whole Internet

●Every device on the Internet must follow it

●It works in layers: each layer does one job and passes data to the next

●Application protocols like HTTP, FTP and SMTP sit on top and rely on TCP/IP below

Application

HTTP • HTTPS • FTP • SMTP • POP3 • Telnet

Transport

TCP: splits data, checks delivery

Internet

IP: addresses and routes packets

Network access

PPP • Ethernet • Wi-Fi: the physical link

Data goes DOWN the layers when sending and UP when receiving.

TCP and IP: Two Jobs, One Team

TCP + IP

TCP/IP is named after its two most important protocols.

TCP — Transmission Control Protocol

Splits the message into packets and numbers them

Checks that every packet arrives

Asks for lost packets to be sent again

Puts packets back in the right order

Result: reliable delivery

IP — Internet Protocol

Gives every device an IP address

Puts source and destination IP on each packet

Routers read the IP address to forward packets

Does not check whether packets arrive

Result: addressing and routing

POP3: Post Office Protocol 3

POP3

●The protocol for RECEIVING email

●Your email program logs in to the mailbox on the mail server and downloads new messages

●By default the server then deletes its copy, so mail lives on your device

●You can read the downloaded mail offline

WHAT HAPPENS

1.  Email program logs in to the mailbox

2.  New messages are downloaded

3.  Server deletes its copy (default)

4.  You read the mail, even offline

(Another protocol, IMAP, keeps mail on the server.)

Telnet: Remote Login

TELNET

●Lets you log in to another computer over the network and run text commands on it

●Your keyboard input goes to the remote machine; its output appears on your screen

●Default port 23

●Not secure: everything, even the password, travels as plain text. SSH has replaced it

$ telnet server.example.com

login: student

Password: ********

Welcome to server.example.com

student@server:~$ ls

notes.txt  report.doc

The commands run on the REMOTE computer. Useful for administration, but unsafe on open networks.

VoIP

Cheap and flexible, but only as good as your connection.

ADVANTAGES

One network for voice, video and data

LIMITATIONS

Needs a good Internet connection

Internet or power failure stops calls

Calls can be intercepted if not encrypted

The Internet vs the World Wide Web

WWW

Often confused, but not the same thing:

THE INTERNET

The global network of networks

Hardware: cables, routers, servers

Carries many services: email, FTP, VoIP and the web

Began with ARPANET

THE WORLD WIDE WEB (WWW)

One service that runs on the Internet

Linked web pages (hypertext) found using URLs

Built on HTTP, HTML and browsers

Invented by Tim Berners-Lee at CERN (1989–91)

XML: Extensible Markup Language

XML

●Designed to store and transport data, not to display it

●Extensible: you invent your own tags, such as <student>

●Self-descriptive: the tags say what the data means

●Strict rules: every tag closed, properly nested, one root tag, case-sensitive

XML EXAMPLE

Tags like <name> and <class> are made up by the author. HTML would not know them, but any program can read them.
