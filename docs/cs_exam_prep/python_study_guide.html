🥞 Type I: Linear Data Structure — Stacks (LIFO) (3 Marks)

5 Questions (Guaranteed Question every year!)
2026 Stack Implementation 3 Marks Push / Pop
Q30 (a). A stack named FruitStack, implemented using list, contains records of some fruits. Each record is represented as a list containing [Fruit_Name, Price].
Write the following user-defined functions in Python to perform operations on FruitStack:
• PushFruit(FruitList): It takes FruitList containing multiple records of fruits as argument. It pushes only those fruits into FruitStack whose price is greater than 100.
• PopFruit(): It pops and displays the topmost record from FruitStack. If FruitStack is empty, it should display "Underflow".
✅ Official CBSE Marking Scheme Code:
FruitStack = []

def PushFruit(FruitList):
    for fruit in FruitList:
        if fruit[1] > 100:       # Check condition: price > 100
            FruitStack.append(fruit)

def PopFruit():
    if len(FruitStack) == 0:     # Check for empty stack (Underflow)
        print("Underflow")
    else:
        record = FruitStack.pop()
        print("Popped Record:", record)
Marking Scheme Rubric: (1½ Marks for PushFruit: ½ mark for loop, ½ mark for condition check, ½ mark for append) + (1½ Marks for PopFruit: ½ mark for checking underflow, ½ mark for pop(), ½ mark for printing).

2025 Stack Implementation 3 Marks Push / Pop
Q30. A stack, named ClrStack, contains records of some colors. Each record is represented as [Color_Name, Code].
Write the following functions in Python:
• PushColor(Colors): Takes a dictionary or list of colors and pushes into ClrStack only those colors whose name starts with vowel ('A', 'E', 'I', 'O', 'U').
• PopColor(): Removes and displays the color from ClrStack. If the stack is empty, displays "Stack Empty".
✅ Official CBSE Marking Scheme Code:
ClrStack = []

def PushColor(Colors):
    for c in Colors:
        if c[0][0].upper() in ['A', 'E', 'I', 'O', 'U']:
            ClrStack.append(c)

def PopColor():
    if not ClrStack:   # Or len(ClrStack) == 0
        print("Stack Empty")
    else:
        val = ClrStack.pop()
        print("Popped:", val)
Marking Scheme Rubric: (1½ Marks for PushColor, 1½ Marks for PopColor with empty check)
2022 Conceptual + Code 2 Marks LIFO Order
Q1. “Stack is a linear data structure which follows a particular order in which the operations are performed.”
What is the order in which insertion and deletion are performed in a Stack? Also explain with real-life example.
✅ Official CBSE Marking Scheme Answer:

Order: LIFO (Last In First Out) or FILO (First In Last Out).

In a stack, both insertion (Push) and deletion (Pop) take place from the same end, called the TOP of the stack.

Real-Life Examples: Pile of dinner plates, stack of books, bangles in a hand, CD holder tray.

Marking Scheme Rubric: (1 mark for LIFO / FILO, 1 mark for real life example)

2026 File Function 3 Marks Character / Digit Counting
Q29. (a) Write a Python function that counts and returns the number of digits appearing in the text file "Space.txt".
For example, if the file contains:
"Apollo 11 was the American spaceflight that first landed humans on the Moon in 1969. The ISS orbits Earth at 400 km."
The function should return 9 (digits: 1, 1, 1, 9, 6, 9, 4, 0, 0).
✅ Official CBSE Marking Scheme Code:
def CountDigits():
    count = 0
    with open("Space.txt", "r") as f:
        data = f.read()
        for ch in data:
            if ch.isdigit():
                count += 1
    return count

# Alternatively using open and close:
def CountDigits():
    f = open("Space.txt")
    data = f.read()
    count = sum(1 for ch in data if ch.isdigit())
    f.close()
    return count
Marking Scheme Rubric: (½ Mark for opening file in read mode) + (½ Mark for reading contents) + (1 Mark for iterating and checking isdigit()) + (½ Mark for counting) + (½ Mark for return/close).
2025 File Function 3 Marks Line Filtering
Q29. (a) Write a Python function that displays all the lines containing the word 'vote' from a text file "Elections.txt".
For example, if the file contains:
In an election many people vote to choose their representative.
The candidate getting the maximum share of votes stands elected.
Normally, one person has to vote once.
The process of voting may vary with time and region.

Output should be:
In an election many people vote to choose their representative.
Normally, one person has to vote once.
✅ Official CBSE Marking Scheme Code:
def PrintVote():
    with open("Elections.txt", "r") as f:
        lines = f.readlines()
        for line in lines:
            words = line.split()
            if "vote" in words:   # Checks exact word 'vote'
                print(line.strip())
Marking Scheme Rubric: (½ Mark for opening file) + (½ Mark for reading lines) + (½ Mark for splitting into words) + (1 Mark for condition 'vote' in words) + (½ Mark for displaying matching lines).
2023 File Function 3 Marks readlines() Word Counting
Q27. Write the definition of a Python function named LongLines() which reads the contents of a text file "STORY.TXT" and displays those lines which have more than 5 words in them. Also count and display total such lines.
✅ Official CBSE Marking Scheme Code:
def LongLines():
    count = 0
    f = open("STORY.TXT", "r")
    lines = f.readlines()
    for line in lines:
        words = line.split()
        if len(words) > 5:
            print(line.strip())
            count += 1
    print("Total such lines:", count)
    f.close()
Marking Scheme Rubric: (½ Mark for open/close) + (1 Mark for readlines & loop) + (1 Mark for len(words) > 5) + (½ Mark for count & display).

📦 Type III: Binary File Handling with pickle (3–5 Marks)

4 Major Exam Questions
2026 Binary Search & Update 5 Marks (2 + 3) pickle.load & seek/tell
Q36. A binary file "RESOURCES.DAT" contains records stored as tuples of format: (Res_ID, Name, Subject, Charges).
Write Python functions:
(i) Add(): To input details of a resource person and write into RESOURCES.DAT.
(ii) Update(): To increase the Charges of each resource person by 500 in the binary file.
✅ Official CBSE Marking Scheme Code:
import pickle

# (i) Add new record to binary file
def Add():
    f = open("RESOURCES.DAT", "ab")   # Append binary mode
    rid = int(input("Enter Resource ID: "))
    name = input("Enter Name: ")
    sub = input("Enter Subject: ")
    charges = float(input("Enter Charges: "))
    record = (rid, name, sub, charges)
    pickle.dump(record, f)
    f.close()

# (ii) Update records using rb+ mode and seek()/tell()
def Update():
    f = open("RESOURCES.DAT", "rb+")  # Read/Write binary mode
    try:
        while True:
            pos = f.tell()            # Capture byte offset before reading
            record = pickle.load(f)
            rec_list = list(record)   # Convert tuple to mutable list
            rec_list[3] += 500        # Increase charges by 500
            f.seek(pos)               # Rewind pointer back to start of record
            pickle.dump(tuple(rec_list), f) # Overwrite updated record
    except EOFError:
        f.close()
        print("All records updated successfully.")
Marking Scheme Rubric: (2 Marks for Add() with pickle.dump in 'ab' mode) + (3 Marks for Update(): 1M for 'rb+' mode, 1M for while loop with EOFError exception, 1M for f.tell(), seek(pos) and pickle.dump).
2024 Binary Copy Filter 3 Marks pickle.dump / load
Q34 (ii). Consider a binary file, items.dat, containing records stored in dictionary format: {item_id: [item_name, amount]}.
Write a function, Copy_new(), that copies all records whose amount is greater than 1000 from items.dat to new_items.dat.
✅ Official CBSE Marking Scheme Code:
import pickle

def Copy_new():
    f_in = open("items.dat", "rb")
    f_out = open("new_items.dat", "wb")
    try:
        data = pickle.load(f_in)
        filtered = {}
        for k, v in data.items():
            if v[1] > 1000:
                filtered[k] = v
        pickle.dump(filtered, f_out)
    except (EOFError, FileNotFoundError):
        pass
    finally:
        f_in.close()
        f_out.close()
Marking Scheme Rubric: (½ Mark for opening files in 'rb' and 'wb' modes) + (1 Mark for pickle.load() & iteration) + (1 Mark for condition v[1] > 1000) + (½ Mark for pickle.dump() & closing files).

📊 Type IV: CSV File Handling with csv module (3–4 Marks)

3 Major Exam Questions
2026 CSV Reader & Filter 3 Marks csv.reader
Q33. A csv file "States.csv" contains data about states of India. Each record consists of: [State_Name, Capital, Population, Literacy_Rate].
Write a Python function CountHighLiteracy() that reads "States.csv" and counts and displays the number of states with Literacy_Rate greater than 85%.
✅ Official CBSE Marking Scheme Code:
import csv

def CountHighLiteracy():
    count = 0
    with open("States.csv", "r", newline='') as f:
        reader = csv.reader(f)
        for row in reader:
            if row:   # Guard against blank lines
                if float(row[3]) > 85.0:
                    print(row[0], "-", row[3] + "%")
                    count += 1
    print("Total States with >85% Literacy:", count)
    return count
Marking Scheme Rubric: (½ Mark for import csv & open) + (1 Mark for csv.reader() and iteration) + (1 Mark for float(row[3]) > 85 condition) + (½ Mark for counting & displaying).
2024 CSV Writerow 4 Marks csv.writer
Q32. Write a function in Python, Add_Device(), to add records of electronic devices to a csv file "Device.csv". Each record contains: [Device_ID, Device_Name, Price]. Prompt user for number of records to enter.
✅ Official CBSE Marking Scheme Code:
import csv

def Add_Device():
    with open("Device.csv", "a", newline='') as f:
        writer = csv.writer(f)
        n = int(input("How many devices to add? "))
        for i in range(n):
            did = input("Enter Device ID: ")
            dname = input("Enter Device Name: ")
            price = float(input("Enter Price: "))
            writer.writerow([did, dname, price])
        print(f"{n} device records successfully added.")
Marking Scheme Rubric: (1 Mark for open in 'a' mode with newline='') + (1 Mark for csv.writer()) + (1 Mark for input loop) + (1 Mark for writerow()).
